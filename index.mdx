Weaviate is an open-source, cloud-native vector database that stores both objects and vectors. It enables semantic search, hybrid search, retrieval-augmented generation (RAG), and image search — all in a single, scalable platform built with Go.

## Get started in 3 steps

<Steps>
  <Step title="Deploy Weaviate">
    Run Weaviate locally with Docker or deploy to Kubernetes. Weaviate exposes REST on port `8080` and gRPC on port `50051`.

    ```bash
    docker run -p 8080:8080 -p 50051:50051 cr.weaviate.io/semitechnologies/weaviate:1.36.0
    ```
  </Step>
  <Step title="Create a collection">
    Define a collection with a schema and choose a vectorizer module to automatically generate embeddings on import.

    ```python
    import weaviate
    from weaviate.classes.config import Configure, Property, DataType

    client = weaviate.connect_to_local()
    client.collections.create(
        name="Article",
        properties=[Property(name="content", data_type=DataType.TEXT)],
        vector_config=Configure.Vectors.text2vec_model2vec(),
    )
    ```
  </Step>
  <Step title="Import data and search">
    Insert objects — Weaviate auto-generates vectors — then run semantic or hybrid search.

    ```python
    articles = client.collections.get("Article")
    articles.data.insert_many([
        {"content": "Vector databases enable semantic search"},
        {"content": "Weaviate supports hybrid search capabilities"},
    ])

    results = articles.query.near_text(query="semantic search", limit=1)
    print(results.objects[0].properties)
    ```
  </Step>
</Steps>
