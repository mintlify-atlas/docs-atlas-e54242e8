Generative modules connect Weaviate to large language models (LLMs). After a search retrieves relevant objects, you can pass them to an LLM in the same query — without writing any intermediate application code. This pattern is called retrieval-augmented generation (RAG).

Weaviate supports two generative query modes:

- **Single prompt** — sends each retrieved object individually to the LLM with a per-object prompt template.
- **Grouped task** — sends all retrieved objects together with a single prompt, useful for summarization or comparison.

## Available generative modules

Weaviate supports 14 generative module integrations. See the full module list and configuration below.

### Full module list

## Enabling a generative module

Add the module name to `ENABLE_MODULES` when starting Weaviate:

```bash
docker run -p 8080:8080 -p 50051:50051 \
  -e ENABLE_MODULES=text2vec-openai,generative-openai \
  -e OPENAI_APIKEY=sk-... \
  cr.weaviate.io/semitechnologies/weaviate:latest
```

<Note>
  You typically enable both a vectorizer module and a generative module together. The vectorizer handles embedding at import and query time; the generative module handles the LLM call after retrieval.
</Note>

## Configuring a generative module in a collection

Specify the generative module when creating a collection. This sets the default LLM for all generative queries on that collection.

<AccordionGroup>
  <Accordion title="OpenAI (generative-openai)">
    ```python
    import weaviate
    from weaviate.classes.config import Configure

    client = weaviate.connect_to_local()

    client.collections.create(
        name="Article",
        vector_config=Configure.Vectors.text2vec_openai(),
        generative_config=Configure.Generative.openai(
            model="gpt-4o",
        ),
    )
    ```

## Using generative search in queries

Once a collection has a generative module configured, add a `generate` clause to any search query.

### Single prompt

A single prompt sends each result object to the LLM separately. Use `{property}` placeholders to reference object properties.

```python
articles = client.collections.get("Article")

response = articles.generate.near_text(
    query="climate change impacts",
    limit=3,
    single_prompt="Summarize this article in one sentence: {title}. Content: {body}",
)

for obj in response.objects:
    print(obj.generated)
```

### Grouped task

A grouped task sends all retrieved objects together in a single LLM call. This is useful for synthesis, comparison, or multi-document summarization.

```python
response = articles.generate.near_text(
    query="renewable energy",
    limit=5,
    grouped_task="Based on these articles, what are the three most important trends in renewable energy?",
)

print(response.generated)
```

### Hybrid search with generation

Generative queries work with any search type — vector, keyword, or hybrid:

```python
response = articles.generate.hybrid(
    query="solar panel efficiency",
    alpha=0.75,
    limit=4,
    grouped_task="Summarize the key findings about solar panel efficiency from these articles.",
)

print(response.generated)
```
